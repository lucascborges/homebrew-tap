# Homebrew Tap for LiteBridge Desktop 🌉

Official Homebrew Tap for [LiteBridge Desktop](https://github.com/lucascborges/LiteBridge-Desktop).

## Installation

```bash
# Add this tap
brew tap lucascborges/tap

# Install LiteBridge Desktop with automatic Gatekeeper quarantine bypass
brew install --cask --no-quarantine litebridge-desktop
```

## Update

```bash
brew update
brew upgrade --cask litebridge-desktop
```

## Uninstall

```bash
brew uninstall --cask litebridge-desktop
brew untap lucascborges/tap
```
